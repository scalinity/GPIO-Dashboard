# Real Pi, 2026-10-25

The app's own UI and Rust side against the bench Pi, driven in the Tauri window (`tauri dev`) by
fixed scenario files. Nothing physical was built or rewired; only pins nothing else claims were
probed or driven, and never GPIO0 to GPIO3.

## The Pi

- Raspberry Pi 5 Model B Rev 1.1, Kali GNU/Linux Rolling, Python 3.14.8, also running Pi-hole,
  Docker, an air monitor and other services.
- apt's `python3-libgpiod` 2.2.5 (gpiod 2.2.0, `request_lines` present), `python3-websockets` 17.1,
  `pinctrl`; the user is in `gpio`. The agent installer's apt step was a no-op.
- GPIO17 is held by the air monitor (`consumer="lg"`, input, pull-up).
- I2C was off (`/dev/i2c-*` missing). It was turned on at the owner's request:
  `dtparam=i2c_arm=on` added to `/boot/firmware/config.txt` (backup `config.txt.bak-2026-10-25`),
  `i2c-dev` in `/etc/modules-load.d/i2c-dev.conf`, and applied live with `dtparam` and `modprobe`
  (no reboot). GPIO2 and GPIO3 now read SDA1 and SCL1.

## Not run on this Pi, and why

- **Tutorial programs and the Toggle LED checkpoint.** They use `RPi.GPIO` or `gpiozero`. Kali's
  `RPi.GPIO` is Debian's 0.7.1a4, which predates the Pi 5's RP1 and maps SoC GPIO memory it does
  not know, and gpiozero falls back to it. Kali packages neither `lgpio` nor `rpi-lgpio`, and pip's
  `lgpio` 0.2.2.0 does not build for Python 3.14 (its SWIG typemap calls `PyInt_FromLong`). On
  Raspberry Pi OS, `rpi-lgpio` provides a Pi 5 `RPi.GPIO`, and the installer adds it when apt has it.
- **Anything needing a built circuit**: the bench fixtures, step confirmation, divergence badges on
  a real mismatch, and the remaining items of `HIL_CHECKLIST.md`.

## Left as found

Afterwards each probed pin was set back to unconfigured with its pull unchanged (`pinctrl set N
no`), which leaves all 28 pins exactly as they read before the first test, the uploaded test script
was removed from `/tmp/gpio_dashboard`, and quitting the app (with the fix above) stopped the agent. The agent's files stay in `~/gpio-dashboard-agent`, as after any deploy. I2C stays on.
